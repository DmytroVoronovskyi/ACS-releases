# Animation Constructor Studio — Releases

Готові Windows-випуски Animation Constructor Studio.

[Завантажити останній випуск](https://github.com/DmytroVoronovskyi/ACS-releases/releases/latest)

У Assets оберіть **AnimationConstructorStudio.exe**. Файл **latest.json** містить підписані дані для оновлювача ACS.

Для переходу зі старих версій, які завантажують оновлення з Google Drive, один раз закрийте ACS і замініть EXE новим. Папки проєктів та налаштування залишаються на місці.

Цей репозиторій містить лише готові випуски та документацію, без вихідного коду. Код не публікується під відкритою ліцензією.
